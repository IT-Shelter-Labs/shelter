# Напарник в Minecraft Java Edition

Джарвис входит в ваш мир **отдельным игровым персонажем**. Игрок видит его
как обычного участника мира. Его скин и ник — от игрового аккаунта напарника;
VRM-модель с рабочего стола в Minecraft не импортируется. Голосовые ответы
по-прежнему звучат на компьютере через выбранного персонажа Джарвиса.

## Первое подключение

1. Запустите свой сервер или откройте одиночный мир для сети: **Esc → Открыть
   для сети**. Сохраните число порта из сообщения Minecraft. Для игры на том
   же компьютере адрес по умолчанию `127.0.0.1`; стандартный порт отдельного
   сервера — `25565`, у LAN-мира свой. Кнопка «Найти порт локального мира»
   проверяет журнал стандартного лаунчера; для других лаунчеров введите порт вручную.
2. В Джарвисе откройте **Игры → Minecraft → Отдельный аккаунт**. Если это
   первое подключение, нажмите **Установить клиент**. Для установки нужен
   Node.js 22+ с npm; Java для самого напарника не требуется.
3. Укажите **свой** игровой ник и нажмите **Подключить напарника**. Когда
   появится код, откройте страницу Microsoft кнопкой в окне. Войдите в
   **другой аккаунт** с доступом к Java Edition — тот, который будет напарником.
   Если у вас включён список разрешённых игроков, добавьте ник напарника.
4. Статус **В мире** показывает имя напарника, версию, координаты, игровой
   режим, предмет в руке и инвентарь.
   Если он не появился рядом, подойдите к точке входа или спавна сервера.

Режим без Microsoft доступен только для **уже настроенного локального
тестового сервера без авторизации**. Он не меняет настройки мира и не
отключает авторизацию. Для одиночного мира используйте Microsoft. Порт и
прочие настройки сохраняются в `data/minecraft.json`, вход — отдельно в
`data/minecraft-auth/`. Не передавайте эту папку; кнопка **Сбросить вход
Minecraft** удаляет только сохранённый вход напарника. Интеграция не
стартует сама и не переподключается без пользователя.

## Что сказать

Позовите своего активного персонажа как обычно. Пока напарник в мире,
знакомые игровые фразы вроде «скажи свои координаты» и «добудь доски»
работают и без слов «в Minecraft». Если фраза двусмысленная, добавьте это
уточнение. В чате напишите `!jarvis` перед командой. Проверяется игровой
идентификатор автора, а при входе Microsoft — ещё и подпись сообщения.
Если ваш сервер на этом же компьютере не подтверждает подписи, отключите
напарника, включите **Доверять чату своего локального мира** и подключите его
снова. На удалённых серверах при непроверяемой подписи используйте голос.

| Действие | Голосом или в поле Джарвиса | В игровом чате |
| --- | --- | --- |
| Подойти | В Minecraft подойди ко мне | `!jarvis подойди ко мне` |
| Следовать | Иди за мной в Майнкрафте | `!jarvis иди за мной` |
| Узнать координаты | Скажи, где ты находишься | `!jarvis координаты` |
| Узнать игровой режим | Какой у тебя игровой режим? | `!jarvis игровой режим` |
| Сменить режим с разрешения сервера | Смени игровой режим на выживание | `!jarvis смени режим на выживание` |
| Охранять от враждебных мобов | Защищай меня | `!jarvis защищай меня` |
| Телепортироваться | Телепортируйся ко мне | `!jarvis телепортируйся ко мне` |
| Остановить | В Minecraft стоп | `!jarvis стоп` |
| Прочитать список вещей | В Minecraft покажи инвентарь | `!jarvis инвентарь` |
| Добыть дерево | В Minecraft добудь четыре дубовых брёвна | `!jarvis добудь 4 дубовых бревна` |
| Запастись досками | Добудь восемь дубовых досок | `!jarvis добудь 8 дубовых досок` |
| Скрафтить предмет | В Minecraft сделай восемь досок | `!jarvis скрафти 8 досок` |
| Передать предмет | В Minecraft передай мне две доски | `!jarvis передай 2 доски` |
| Подготовить и принести | В Minecraft подготовь и принеси четыре дубовые доски | `!jarvis подготовь и принеси 4 дубовые доски` |
| Добыть и подготовить камень | Дай мне четыре каменных блока | `!jarvis дай мне четыре каменных блока` |
| Построить | Построй стену из шести досок | `!jarvis построй стену из шести досок` |
| Порыбачить с удочкой из инвентаря | Порыбачь | `!jarvis порыбачь` |

Для доставки напарник проверяет запас, рецепты своей версии, инструменты и блоки
в загруженной области вокруг себя. В выживании он может строить цепочку из добычи,
крафта, установки верстака или печи и переплавки. Например, для камня цепочка может
начаться с дерева и деревянной кирки, затем использовать булыжник и уголь. В творческом
режиме на серверах с подтверждением инвентаря он может взять недостающий предмет
из творческого инвентаря. Передача происходит рядом с владельцем.

Фраза «дай доски» допускает любой вид досок. Русские формы вроде «две железные
кирки» опираются на словарь установленного клиента Minecraft. Для модов подходят
точные ID, если они присутствуют в реестре игрового подключения и клиент знает рецепт.
Из приложения можно выбрать предмет, взять его в руку или передать выбранное количество.
Рядом виден текущий шаг. Кнопка остановки и `!jarvis стоп` прерывают дальнейшие шаги.
Уже добытое и построенное остаётся в мире. При остановке переплавки содержимое
печи остаётся в печи.
В «Игровых задачах» видны текущее действие, очередь и восемь последних результатов
текущего подключения. Отмена отдельной задачи позволяет выполнить остальные по очереди.

Для свободной формулировки разговорная модель получает фактическое состояние
Minecraft и может вызвать доступное игровое действие или последовательность
действий. Удалённое подключение модели получает эти данные при обработке запроса.
Источником координат, режима и итогов действий служит игровой клиент.
Ответы в чат клиента идут под его игровым ником.

Планирование ограничено загруженными блоками, известными рецептами, поддерживаемой
переплавкой и возможностями текущего адаптера. Строительство поддерживает линии,
стены и площадки до 16 блоков за действие. Охрану можно включить до остановки,
отключения или выхода из области видимости владельца.

## Открыть инвентарь в игре

### Отдельный игровой аккаунт на Paper 1.21.5

1. В Джарвисе откройте **Игры → Minecraft → Отдельный аккаунт → Инвентарь в игре**.
   Подготовьте плагин ShelterInventory, положите JAR в папку `plugins` своего сервера
   с включённой авторизацией игроков и перезапустите сервер.
2. Подключите напарника. Войдите своим аккаунтом и с правом оператора выполните
   `/shelterinventory link <ник_напарника>`. Плагин запомнит UUID обоих аккаунтов.
3. Подойдите к напарнику ближе чем на восемь блоков и напишите `!inv`.
   Доступны его сумка, хотбар, броня и руки. Левый или правый клик переносит и делит стопки,
   Shift-клик передаёт их целиком в пределах свободного места. Shift-клик по подходящей
   броне из своего инвентаря надевает её, если слот свободен.

Доступ можно убрать через `/shelterinventory unlink`. В ванильном мире с обычным
«Открыть для сети» доступны список `!jarvis инвентарь` и управление из панели Джарвиса.
Серверный экран для отдельного аккаунта требует ShelterInventory.

### Одиночный мир или сервер NeoForge 1.21.1

В локальной сборке **Игры → Minecraft → Без отдельного аккаунта → NeoForge 1.21.1**
можно подготовить адаптированный мод из предоставленного проекта `mineCodehelper`.
Положите JAR в `mods` профиля Minecraft 1.21.1 с NeoForge 21.1.262. Для отдельного
сервера этот же мод нужен на сервере и клиентах, которые подключаются к нему.
Если там уже установлен мод с ID `aicompanion`, используйте один JAR с этим ID.

Вызовите своего персонажа через `/companion summon`, подойдите и напишите `!inv`.
То же меню открывается правым кликом по персонажу или командой `/companion inventory`.
В меню шесть слотов экипировки, сумка персонажа и вещи игрока. Оно использует
инвентарь из проекта `mineCodehelper`, включая перемещение между владельцем и напарником,
ограничения на броню и штатное сохранение экипировки в мире. Настройки модели и
поведения этого персонажа находятся в самом моде.

## Без отдельного аккаунта

Откройте **Игры → Minecraft → Без отдельного аккаунта**, выберите платформу
и нажмите **Подготовить мод Minecraft**. Джарвис сохранит файл в `data/game-mods`
и предложит показать его в папке. Оба варианта работают с миром на этом
компьютере. Связь с игрой не меняет параметры входа игроков.

### Paper 1.21.11

1. Положите JAR `shelter-npc-0.2.0.jar` в `plugins` собственного Paper-сервера
   с Java 21 и обычной авторизацией входящих игроков. При обновлении удалите
   из `plugins` предыдущую версию на остановленном сервере.
2. Войдите в игру с правом `shelternpc.own` и выполните `/shelternpc pair`.
   Нажмите на личное сообщение, чтобы скопировать код. Подключитесь из
   Джарвиса и нажмите **Вызвать напарника**.
3. Персонаж использует модель и стандартный скин игрока Minecraft. Он может
   подойти, следовать по доступному пути, остановиться и сообщить координаты.
   Игрового режима и инвентаря игрока у персонажа Paper нет.
4. **Отключить напарника** убирает персонажа. Команда `/shelternpc stop` также
   отзывает код. Плагин слушает только `127.0.0.1:27846`.

Для пересборки JAR запустите `android\gradlew.bat -p games\minecraft-npc jar`
с JDK 21. Поместите `games/minecraft-npc/build/libs/shelter-npc-0.2.0.jar`
в `games/minecraft-npc/distribution/` перед сборкой приложения.

### Fabric 1.21.11 с Carpet 1.4.193

1. Установите [Fabric](https://fabricmc.net/use/) и [Carpet 1.4.193](https://github.com/gnembon/fabric-carpet/releases/tag/1.4.193).
   Используйте одиночный мир с разрешёнными командами или собственный
   сервер с правами оператора.
2. Распакуйте ZIP из Джарвиса в корень мира. В нём должен появиться файл
   `scripts/sheltercompanion.sc`. В игре выполните `/script load sheltercompanion`,
   затем `/sheltercompanion pair`.
3. В течение минуты выберите получившуюся папку `scripts` в Джарвисе и
   нажмите **Вызвать напарника**. Carpet создаёт игрока `ShelterJarvis`
   внутри мира. Он стартует в выживании. Джарвис считывает его режим из игры.
   Если при переключении в Джарвис одиночный мир ставится на паузу, нажмите
   `F3+P` в Minecraft, чтобы отключить паузу при потере фокуса.
4. В этом варианте движение рассчитано на открытое место. Для отключения
   используйте кнопку в Джарвисе или `/sheltercompanion disconnect` в мире.
   Обмен идёт через локальные файлы `scripts/sheltercompanion.data`.

В обоих вариантах ответы появляются в личном игровом чате владельца после
вызова напарника. Подготовка пакетов и обмен данными проверяются отдельно от
входа в живой мир. Paper собран с API 1.21.11. Вызов персонажа, отображение
скина и движение в пользовательской игре требуют отдельной проверки на
Paper и Fabric. Локальный мод NeoForge работает отдельно и описан выше.

## Игровые действия с отдельным аккаунтом

- Следование длится до пяти минут и уступает новой задаче. Добыча, крафт и
  передача — до 16 за команду; одна задача за раз.
- Добыча ограничена ближайшими обычными блоками: брёвнами, камнем, землёй,
  песком, булыжником и угольной рудой. Нужный инструмент должен быть в инвентаре
  напарника. Подтверждение различает сломанные блоки и реально подобранные вещи.
- Бросьте инструмент рядом с напарником и проверьте его инвентарь. Во время
  добычи он сам экипирует подходящий инструмент из имеющихся. Игровой режим
  назначает сервер. Если у вас права оператора, вы можете сменить его штатной
  командой `/gamemode survival <ник>` или `/gamemode creative <ник>`.
- Крафтит доски, палки, верстак и факелы при наличии ингредиентов. Выход зависит
  от размера партии рецепта. При передаче выбрасывает предметы рядом с вами;
  их нужно подобрать. Команда не трогает инвентарь игрока.
- «Добудь доски» проверяет запас напарника, при необходимости ищет ближайшие
  брёвна нужной породы, подбирает их и крафтит доски. «Доски» без уточнения —
  дубовые. Если дерево недоступно, можно передать брёвна напарнику вручную.
- «Дай мне доски» означает четыре дубовые доски, если количество не указано.
  Если готовых досок мало, напарник использует доступные брёвна из своего
  инвентаря, подходит и выбрасывает ровно запрошенное количество.
- Телепорт использует штатную команду игры. Она сработает только если мир
  разрешает команды и аккаунту напарника выдано право на телепорт.
  Сама интеграция никаких прав не выдаёт. Без этих прав можно сказать «подойди
  ко мне», если напарник находится неподалёку.
- **Остановить действие** отменяет путь и добычу. Предмет или блок, уже
  изменённый сервером до остановки, не откатывается.
- Галочка **Разговаривать в игре через выбранную модель** добавляет беседу
  после `!jarvis`. По умолчанию она выключена. При включении модели передаются
  текст обращения, имя персонажа и до трёх предыдущих пар реплик этого
  подключения. Память, инструменты рабочего стола и посторонний чат ей не
  передаются. Если выбрана облачная модель, этот текст уйдёт провайдеру.
- **Озвучивать ответы из игры голосом персонажа** читает чат-ответы на вашем
  ПК. Другие участники слышат их только если вы отдельно передаёте звук ПК.
- **Писать все ответы Джарвиса в игровой чат** дублирует ответы на голосовые
  и текстовые вопросы, включая погоду. Галочка включена по умолчанию. Эти
  сообщения читают остальные игроки. Если выключить галочку при подключении,
  игровые ответы продолжат появляться в чате.

## Ограничения и проверки

Используйте свои миры и серверы, где разрешены дополнительные клиенты.
Поддерживается Java Edition; Bedrock, Realms, серверы с обязательными
модами, голосовой чат внутри игры, автономное выживание и строительство
не входят в этот выпуск. Напарник не распознаёт авторские постройки: давайте
команды добычи только там, где можно ломать блоки.

В реализации закреплены Mineflayer 4.39.0 и Pathfinder 2.4.5. Версия сервера
определяется при подключении. Автотест интеграции использует локальный
тестовый сервер протокола Java (1.20.4, 1.21.5 и 1.21.11). На 1.20.4 создана площадка,
на которой проверяются движение к игроку, прекращение следования и подтверждение
добычи. На 1.21.5 проверены крафт, доставка и подтверждение передачи по
серверному снимку инвентаря. Там же проверяются смена игрового режима по
пакету и доставка ответа о погоде до игрового чата. Вход Microsoft в этих
автотестах не выполняется.
