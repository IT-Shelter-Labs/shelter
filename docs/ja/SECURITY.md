# セキュリティ上の問題を報告する

[English](../../SECURITY.md) · [Русский](../ru/SECURITY.md) · **日本語** · [简体中文](../zh-CN/SECURITY.md)

リポジトリに非公開の脆弱性報告窓口がある場合は、そちらをご利用ください。トークン、API キー、音声サンプル、個人メモリ、ログ全文は公開 Issue に掲載しないでください。

Shelter はデスクトップユーザーの権限で操作します。MCP サーバー、拡張機能、シェルを使うワークフローは信頼できる提供元から導入してください。ローカル API にはトークンが必要で、スマートフォンはペアリングが必要です。デスクトップの制御 API はローカルでのみ利用し、スマートフォンは対応する接続機能でペアリングしてください。[接続の設定](GUIDE.md)
