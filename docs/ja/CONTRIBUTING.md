# Shelter の開発に参加する

[English](../../CONTRIBUTING.md) · [Русский](../ru/CONTRIBUTING.md) · **日本語** · [简体中文](../zh-CN/CONTRIBUTING.md)

作業用のブランチを作り、課題、変更内容、確認した手順を記載してください。不具合を報告する際は、OS、音声モード、モデル、再現手順と、個人情報や認証情報を除いたログの一部を添えてください。[ビルドとテストの手順](GUIDE.md)

音声処理を変更するときは、サンプルレート、PCM 形式、中断処理、最初の音が出るまでの時間を維持してください。ネイティブ実装とフォールバックの両方を確認します。UI の変更は開発用ブラウザーとネイティブ版の両方でテストしてください。モデルの重み、認証情報、個人メモリ、音声サンプルはコミットに含めないでください。
