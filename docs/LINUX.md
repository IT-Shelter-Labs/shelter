# Shelter на Linux

Архив для Linux x86_64 содержит графическую оболочку, ядро и скрипт установки.
Базовое окружение сборки — Ubuntu 24.04. Поддержка Linux экспериментальная.

Для Ubuntu 24.04 установите системные зависимости:

```bash
sudo apt install python3 python3-venv libportaudio2 libgtk-3-0t64 libwebkit2gtk-4.1-0 libayatana-appindicator3-1 librsvg2-2
```

Распакуйте архив релиза, откройте его папку и запустите:

```bash
python3 tools/install_linux.py --light-recognition
"${XDG_DATA_HOME:-$HOME/.local/share}/Shelter/shelter"
```

Программа устанавливается в `~/.local/share/Shelter` или под `XDG_DATA_HOME`.
Укажите другую новую папку через `--directory` или добавьте `--choose-directory`
для диалога выбора папки (нужен Tk). Ключ `--light-recognition` выбирает Vosk.
Архив автоматически использует вложенный `shelter-desktop`. Из чистых
исходников можно использовать голосовое ядро или указать свой собранный
Linux-исполняемый файл через `--desktop-binary`.

Зависимости Windows исключены платформенными маркерами. Для запуска нужны Python 3.11+, PortAudio,
виртуальное окружение `.venv` и зависимости из `requirements.txt`. Выберите микрофон через
`python main.py --list-devices`. Сначала настройте обычный лёгкий голос и готовые команды.

Tauri ищет `.venv/bin/python` в выбранной папке. Ollama на Linux поставляется отдельно
пакетом для вашей системы. Для работы без неё можно подключить облачную модель.

Для распространённых дистрибутивов дополнительно обычно нужны системные
библиотеки PortAudio, Tk и `playerctl`. Последний используется для действий
`media` через MPRIS: например, Spotify управляется без эмуляции клавиш.
Общая громкость использует `pactl` (PulseAudio или совместимый сервер PipeWire).
Приложения ищутся по desktop-файлам в XDG-каталогах и запускаются через `gio launch`.

## Ограничения

- `type: launch`, `url`, `say`, `overlay`, `media`, `profile` поддерживаются.
- `type: app` — это Windows Store и на Linux намеренно не работает; используйте
  `launch` с именем программы или её путём.
- `type: riot` и Windows-специфичное управление окнами не входят в Linux-версию.
- Управление окнами, питание, Discord-hotkeys и снимок экрана требуют отдельных платформенных адаптеров.
  На Wayland эти действия зависят от порталов и разрешений окружения рабочего стола.
- Секреты Windows DPAPI нельзя перенести на Linux: введите их заново. На Linux файл настроек
  ограничивается правами 0600; вместо токенов в файле предпочтительны переменные окружения.
- CI проверяет Python-логику Linux. Реальные микрофоны, Wayland/X11 и GPU требуют проверки на Linux-машине.
- В `collect.py` есть ввод с клавиатуры и для POSIX-терминалов.

Создавайте отдельные профили и команды под Linux вместо копирования
Windows-путей. Публичный стартовый вариант лежит в `config.public.yaml`.
