# Голосовой ввод и базовые действия

Сначала поставьте курсор в поле поиска, сообщения или документа. Обратитесь
к Джарвису и произнесите команду. Клики происходят там, где сейчас указатель
мыши: поиск кнопок на экране в эти команды не входит.

| Команда | Действие |
|---|---|
| «Кликни на левую кнопку мыши», «нажми ЛКМ» | левый клик |
| «Кликни правой кнопкой мыши», «нажми ПКМ» | правый клик |
| «Нажми среднюю кнопку мыши» | средний клик |
| «Двойной клик левой кнопкой мыши» | двойной клик |
| «Прокрути вниз», «прокрути вверх на пять шагов» | колесо, 1–20 шагов |
| «Нажми Enter», «нажми Tab», «нажми Escape» | соответствующая клавиша |
| «Нажми стрелку вправо», «нажми бэкспейс» | перемещение курсора, стирание |
| «Выдели всё», «скопируй выделенное», «вставь из буфера» | Ctrl+A/C/V |
| «Отмени последнее действие» | Ctrl+Z |

## Сообщение: написать → изменить → отправить

1. В Telegram, поиске или другой программе поставьте курсор в нужное поле.
2. «Джарвис, напиши сообщение: как дела?» — появится `Как дела?`.
3. «Измени сообщение на: Привет, как ты?» — заменится набранный черновик.
4. «Добавь к сообщению: Рад тебя видеть» — дополнит черновик.
5. «Отправь» — отдельно нажмёт Enter в исходном поле. Если приложение настроено
   на Ctrl+Enter, скажите «отправь через контрол энтер».

Можно начать с «напиши сообщение» или «измени сообщение, которое ты написал»:
ассистент спросит текст и воспримет следующую фразу как диктовку.
«Отмени диктовку» или «отмени редактирование» завершит ожидание. «Стоп» также
сбрасывает ожидание следующей фразы. Оно истекает через минуту или при закрытии
сеанса слушания, чтобы после нового обращения обычный вопрос не стал диктовкой.

«Сделай сообщение вежливее», «перепиши сообщение короче» используют подключённую
модель. Это только редактирование: результат автоматически не отправляется.
Для простого набора, замены, кликов и клавиш нейросеть не требуется.

## Просьбы своими словами

Примеры выше — быстрые офлайн-команды, а не обязательные формулировки.
При включённой нейросети можно сказать «тыкни правой мышкой», «опусти
страничку чуть ниже», «в это поле впиши: До встречи!», «припиши к моему тексту:
Спасибо за помощь!», «сделай мой черновик повежливее», «отошли уже набранное».
Смысл разбирается выбранной разговорной моделью; вторая модель не скачивается.

Незнакомая правилам просьба проходит короткую отдельную классификацию до
обычного ответа. Она видит только текущую фразу и наличие своего черновика,
без буфера, снимка, текста чужого поля и истории разговора. Если выбрано
облако, эта фраза отправляется ему. В настройках подключений моделей можно
отключить предварительный разбор (`llm.semantic_input: false`); тогда
инструмент выбирает основной диалог, что менее надёжно на маленькой модели.
Для ответа на уточнение дополнительно сохраняется только одна незавершённая
просьба и заданный вопрос, максимум на минуту и внутри того же разговора.
Например, после «Левой или правой?» можно ответить «правой». «Стоп» и закрытие
сеанса очищают это ожидание; следующий самостоятельный запрос его заменяет.

Параметры проверяются локально. Диктуемый текст должен дословно присутствовать
в текущей фразе. Одна смысловая просьба разрешает одно действие. Неясное
«нажми ту кнопку» вызывает уточнение. Поиск элементов экрана и выбор адресата
этим механизмом не выполняются. Для правки черновика и отдельной отправки
сохраняются проверки исходного поля.

Ollama получает [JSON Schema через format](https://docs.ollama.com/capabilities/structured-outputs).
Другие провайдеры получают инструкцию формата; любой ответ всё равно проходит
одинаковую проверку. Самооценка уверенности модели не является гарантией
правильности. При ошибке разбора действие не выполняется.

В «Команды → проверка фразы» есть флажок «Проверить смысл нейросетью».
Запрос выполняется кнопкой «Проверить», не при каждом набранном символе.
Это предпросмотр намерения, без реального ввода или клика.

Проверка разработчика: `python tools/evaluate_desktop_intent.py` использует
только уже настроенное локальное подключение и ничего не исполняет.
На Gemma 4 E4B разобраны 30/30 контрольных фраз: действия, отрицания,
обычный разговор, неоднозначность и другие функции ассистента. Это небольшой
проверочный набор, не обещание понимания любой фразы или качества других моделей.

## Ограничения

- Текст вводится одной строкой; переводы строк и управляющие символы не
  превращаются в скрытые нажатия Enter. Для нажатия клавиши есть отдельная команда.
- Черновик хранится только в памяти до десяти минут, повторная отправка
  того же черновика блокируется. Получение сообщения адресатом не проверяется:
  приложение подтверждает нажатие клавиши, а не доставку.
- Автозамена разрешена, когда поле Windows UI Automation читается и содержит
  именно набранный черновик. Если окно, поле или его текст изменились, замена
  прекращается. В неподдерживаемом поле выделите текст вручную и используйте
  «напечатай …». Распознанные парольные поля не используются.
- Для уже отправленного сообщения сначала откройте режим редактирования
  в самом мессенджере; затем продиктуйте замену и отдельно подтвердите Enter.
  Автоматического выбора адресата или открытия чужого сообщения нет.
- На Linux X11 клики и клавиши требуют xdotool. Проверяемая автозамена поля
  через Windows UI Automation доступна на Windows; Wayland сообщает об ограничении.
- Разрешение общее с «управлением компьютером» (`llm.tools: pc`). Гостевой голос
  не получает эти действия. Текст после «напиши» не разбирается на команды:
  даже «напиши выключи компьютер и отправь» вводит слова, а не выполняет их.

Новые изменения пока находятся в рабочих исходниках. Публичные EXE/архив,
папка `release/github-source` и установщики в рамках этой доработки не обновляются.

## Серии в браузере

Оставьте браузер с видео на переднем плане и скажите **«Джарвис, следующая
серия»**. Джарвис отправит штатную команду «Далее» медиасессии этого браузера.
Расширение, ключ и выход из полноэкранного режима не нужны. Если плеер не
публикует системное действие «Далее», выбрать номер серии на странице нужно
вручную. При нескольких неразличимых сессиях команда не выполняется.
Отдельный плеер, например Spotify, эта команда не затрагивает.
