# Персонажи, модели и движения

Персонаж объединяет характер, голос и облик. Настройка: страница **«Персонаж»**.
Встроенный персонаж при редактировании сохраняется отдельной копией. Выберите эту
копию после сохранения, если хотите сделать её активной.

## Встроенные персонажи Shelter

Пиппа активна при первом запуске. Выбрать другой пресет можно на странице
«Персонаж». В профиле сохраняется последний выбор. У Мандзю 3D-облик уже
в комплекте, у Юки модель скачивается при выборе. Пресеты с портретом или
инициалом используют HUD, пока вы не подключите 3D-файл.

Для Пиппы откройте **«Страница 3D-модели»** на её карточке и скачайте
`08_Pippa.zip` у автора. Распакуйте архив, нажмите карандаш на карточке Пиппы,
затем **«Облик» → «3D-модель» → «Модель .vrm»**. Выберите блондинку или
серебристую версию, сохраните копию и нажмите **«Выбрать»** на ней. Автор
модели — [loulou_yurika (ねこのゆりか)](https://booth.pm/ja/items/4613310).

## Где взять более интересную аниме-модель

- [VRoid Hub](https://hub.vroid.com/en) — галерея с просмотром моделей в 3D.
  Выбирайте персонажей, у которых автор разрешил скачивание VRM.
- [BOOTH: модели VRM](https://booth.pm/en/search/VRM) — авторские персонажи,
  бесплатные и платные. Убедитесь, что скачивается именно `.vrm`, а не только
  пакет Unity для VRChat или набор текстур.
- Конкретный вариант для знакомства: [Amane / あまね от yousoron-shop](https://booth.pm/ja/items/4911831).
  На странице автора есть бесплатные варианты Type01–Type04 в VRM 0.0. Автор
  разрешает использование и изменение, в том числе коммерческое, с условиями;
  перепродажа запрещена. Это кандидат для личного выбора, а не проверенная на
  этой машине замена заглушки. Не включена в публичную поставку автоматически.
- [VRoid Studio](https://vroid.com/en/studio) — собрать собственный облик и
  экспортировать VRM. Это удобнее для создания узнаваемого персонажа проекта.

Поддерживаются **VRM 0.x и VRM 1.0**, с гуманоидным скелетом, встроенными
текстурами. Файл модели — до 128 МБ. `.vroid`, `.fbx`, `.glb` общего назначения,
Live2D и Unity-пакеты напрямую не подходят. Модели с внешними текстурами
отклоняются: экспортируйте цельный файл. Отсутствующие необязательные кости
допускаются; внешний вид жестов зависит от пропорций и экспорта конкретной модели.

После скачивания: **Персонаж → копия/свой персонаж → Облик → 3D-модель → Модель
.vrm → Сохранить → Выбрать**. Файл копируется в папку персонажа; исходник можно
хранить отдельно. В поле автора сохраните ссылку и условия использования.

Варианты Пиппы и Цукуёми объединяются в одну карточку для каждого персонажа.
В редакторе выбирайте **«Вариант внешности»**, чтобы сменить одежду/контур.
**«+ Облик»** добавляет ещё одну модель этому персонажу с общими голосом и характером.

Право использовать модель в видео и право распространять её файл с приложением
могут различаться. Для публичной сборки отдельно проверьте разрешение на
распространение. Условия относятся к каждой модели, а не к формату VRM в целом.
[Пояснение VRoid об условиях моделей](https://vroid.pixiv.help/hc/en-us/articles/4402614652569-Do-VRoid-Studio-s-sample-models-come-with-conditions-of-use).

## Что уже можно сказать

Сначала разбудите ассистента обычным обращением или горячей клавишей.
Имя персонажа **не меняет слово пробуждения**: по умолчанию это «Джарвис».

| Команда | Результат |
| --- | --- |
| «Помаши мне рукой» | Короткий жест рукой |
| «Кивни» | Кивок |
| «Поклонись» | Поклон |
| «Танцуй» | Танец в выбранном темпе |
| «Танцуй в темпе 130» | Танец с темпом 130 BPM (допустимо 50–200) |
| «Танцуй под бит» / «Танцуй под музыку» | Оценка ритма системного звука |
| «Останови анимацию» / «Хватит танцевать» | Остановка |
| «Стоп» во время движения | Остановить танец/движение и продолжить слушать; работает и после тайм-аута диалога |
| «Встань в исходное положение» / «Вернись на своё место» | Нижний правый угол основного монитора |
| «Увеличь себя» / «Стань больше» | Увеличить размер на 10 процентных пунктов |
| «Уменьши себя» / «Стань меньше» | Уменьшить размер на 10 процентных пунктов |
| «Перейди на второй монитор» | Переход на другой подключённый экран |
| «Перейди в левый верхний угол монитора» | Перемещение в угол текущего экрана |
| «Переместись по центру» | Переход к центру текущего экрана |

Эти фразы работают без языковой модели. «Помахай мне ручкой», «помаши мне своей
кистью» тоже понимаются. Для более свободных формулировок включите языковую модель:
она получает каталог существующих движений и инструмент перемещения. Она выбирает
движение из каталога, а не создаёт новую анимацию на лету.
Жест остаётся видимым до завершения; танец
включается максимум на 30 минут либо до команды остановки.

Первый монитор — основной, остальные упорядочены по расположению слева направо.
«Останови анимацию» также останавливает текущий переход. После смены персонажа
голосом диалог продолжается без повторного обращения «Джарвис».

Голосовой размер ограничен диапазоном 20–400% и сохраняется отдельно для каждого
персонажа. Его же значение видно в редакторе. Карандаш заменяет каталог редактором
в том же окне; кнопка «К персонажам» возвращает каталог. Встроенный персонаж при
сохранении изменений становится отдельной копией — оригинал остаётся доступным.

## Походка и физика

В приложение включены готовые полнотелые движения **Quaternius Universal
Animation Library Standard (CC0)**: спокойная поза, обычная и сдержанная походка,
танец. Источник и контрольные суммы находятся в
`app/public/animations/NOTICE.md`. Размер набора — около 220 КБ; моделей и текстур
из библиотеки в нём нет. Ничего не скачивается во время прогулки.

Персонаж сначала поворачивается по направлению движения, плавно набирает скорость,
после остановки возвращается к зрителю. Фаза шагов зависит от пройденного расстояния,
а длина шага — от роста модели. Кости таза, корпуса, стоп, носков и кистей
анимируются из готового клипа. В редакторе доступен выбор **«Походка»**.

Физика волос, хвоста и одежды использует spring bones и коллайдеры, заложенные
автором VRM. Силы и радиусы пересчитываются при изменении размера персонажа.
Если автор не настроил физику или скелет части тела, приложение не создаст их
автоматически. Это пружинная физика VRM, а не симуляция ткани. У кота-шарика,
например, нет видимых ног: человеческая походка не добавит ему ноги.

Ходьба переносится между VRM 0.x и 1.0 через VRMA. Приветствие раскрытой ладонью,
кивок и поклон теперь тоже готовые авторские клипы из Mesh2Motion (CC0), с движением
пальцев и переходами между позами. Проверены восемь семейств личных моделей; для произвольной
модели с другими пропорциями могут понадобиться индивидуальные правки движения.

«Под бит» использует необязательный `soundcard` и loopback устройства вывода.
Аудио анализируется локально в памяти и не записывается на диск. Оценка требует
4–8 секунд ритмичного звука; речь самого ассистента исключается из оценки.
Это приблизительный анализ энергии, не распознавание музыки или гарантия точного
BPM. При недоступном захвате сохраняется фиксированный темп, а окно показывает
пояснение. Системные звуки и видео тоже могут влиять на оценку. Самостоятельно
при любом звуке танец не включается: нужна команда или ваше действие-сценарий.

## Как добавить собственное движение

Формат — **VRM Animation (`.vrma`)**, переносимый между гуманоидными VRM.
Поддержка опирается на официальный
[@pixiv/three-vrm-animation](https://github.com/pixiv/three-vrm/tree/release/packages/three-vrm-animation),
описание формата — [VRM Animation](https://vrm.dev/en/vrma/).

1. Получите `.vrma` с разрешением автора на нужное использование.
2. **Персонаж → Изменить → Движения персонажа → Импорт .vrma**.
3. Дайте название и голосовую фразу, например «покажи сердечко». Несколько фраз
   разделяются запятыми. Не добавляйте слово пробуждения в саму фразу.
4. Включите «Повторять» для циклического движения. Сохраните и выберите персонажа.
5. Скажите «Джарвис, покажи сердечко». Для завершения — «останови анимацию».

Файл — до 32 МБ, одна анимация — до 10 минут, до 256 анимаций на персонажа.
Встроенные жесты имеют приоритет: своим движениям задавайте другие фразы.

Для создания с нуля: [Blender с VRM Add-on](https://github.com/saturday06/VRM-Addon-for-Blender)
либо другой редактор из [официального списка VRMA](https://vrm.dev/en/vrma/).
Обычный порядок: импортировать VRM, создать позу/ключи костей гуманоидного скелета,
сделать действие, затем экспортировать VRM Animation средствами установленной
версии редактора. Для цикла сделайте начальную и конечную позу одинаковыми.
Названия пунктов экспорта зависят от версии редактора. FBX из Mixamo сначала
требует переноса на гуманоидный скелет и экспорта в VRMA; напрямую он не загружается.

## Музыка и танец одним сценарием

К существующему действию открытия музыки добавьте действие `avatar`:

```yaml
actions:
  - type: url
    url: "spotify:playlist:ВАШ_ID"
  - type: avatar
    animation: dance
    beat: true
    bpm: 120
```

Запуск воспроизведения зависит от вашего действия Spotify: сам URI может только
открыть плейлист. `avatar` управляет движением, а не воспроизведением музыки.
Для собственного движения вместо `dance` укажите его id из JSON персонажа.

## Окно и производительность

«Всегда на экране», «Клики проходят насквозь» и «Прятать в игре» применяются сразу.
Чтобы перетащить персонажа, сначала выключите клики насквозь в настройках.
Невидимый прозрачный слой занимает рабочие области мониторов. Персонаж двигается
внутри него, без маленького обрезающего окна и без отдаления камеры при жесте.
Клики по пустой области проходят к приложениям под ним. Положение персонажа
запоминается локально; при отключении монитора он возвращается на основной экран.
Скрытие в игре не завершает голосовой диалог. Эксклюзивный полноэкранный режим
игры может перекрывать обычные окна Windows; отдельно в нём не проверено.

В копии персонажа доступны размер, походка, микродвижения, субтитры и
20/30/60 FPS. Для слабого ПК начните с 20 FPS и модели с небольшим числом
полигонов/текстур. Скрытое окно не рисует кадры. «Микродвижения» меняют дыхание и
небольшие движения головы; готовые жесты и VRMA проигрываются по своему файлу.

Для точного размера: «размер 200%» / «размер двести процентов» / «увеличь себя до
200%». «Стань больше в два раза», «увеличься вдвое» умножают текущий размер на два;
«стань в два раза меньше» делит его на два. «Увеличь на 50%» умножает на 1.5,
«уменьши на 50%» — на 0.5. Эти варианты отличаются от обычного шага «стань больше»
(+10 процентных пунктов). Выход за диапазон при точном запросе объясняется явно.

## Студия, посадка, аксессуары и артикуляция

Актуальная инструкция: [COMPANION.md](COMPANION.md). Студия находится внутри
редактора персонажа и не управляет его рабочим окном. Случайная артикуляция
заменена разметкой PCM; авто использует фонетический кэш и акустический поток.
