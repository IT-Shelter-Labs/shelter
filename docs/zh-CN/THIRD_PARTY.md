# 第三方许可证与署名

[English](../../THIRD_PARTY.md) · [Русский](../ru/THIRD_PARTY.md) · [日本語](../ja/THIRD_PARTY.md) · **简体中文**

- Quaternius 和 Mesh2Motion 动画采用 CC0。来源及校验和见[动画署名](../../app/public/animations/NOTICE.md)。
- Tauri、Svelte、Three.js、@pixiv/three-vrm 和 Lucide 的版本由 Cargo.lock 和 package-lock.json 固定。许可证见各项目或软件包。
- 原生重采样器使用 Kaiser 窗的多相 FIR 滤波器。测试以 SciPy 为参考，库中未包含 SciPy 代码。
- GigaAM、Vosk、Piper、Qwen 和 Ollama 分别适用各自条款。公开源码快照不包含模型权重或个人克隆语音。
- Android 版使用 [LiteRT-LM 0.19.1](https://github.com/google-ai-edge/LiteRT-LM/tree/v0.19.1)、[Vosk Android 0.3.75](https://github.com/alphacep/vosk-api) 和 [JNA 5.18.1](https://github.com/java-native-access/jna/tree/5.18.1)。Vosk 与 LiteRT-LM 采用 Apache 2.0，JNA 可按 Apache 2.0 或 LGPL 2.1 使用。可下载的 [Qwen3 0.6B](https://huggingface.co/litert-community/Qwen3-0.6B-int4) 和 [俄语 Vosk 包](https://alphacephei.com/vosk/models)采用 Apache 2.0。
- 分享自行导入的 VRM、配饰或语音样本前，请确认其再分发条款。
- 俄语国名来自 [Unicode CLDR](https://github.com/unicode-org/cldr-json)，采用 [Unicode License v3](https://www.unicode.org/license.txt)。首都和英语国名来自 [GeoNames countryInfo](https://download.geonames.org/export/dump/countryInfo.txt)，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。天气数据按国家代码合并，省略没有首都的条目。
- 武器选择和钓鱼逻辑改编自 Mindcraft 及早期的 MinePal 分支。[Mindcraft MIT 声明](../../minecraft/MINDCRAFT-LICENSE) · [MinePal MIT 声明](../../minecraft/MINEPAL-LICENSE)

- Pippa 的头像和 README 封面参考公开提供的 **Pippa** © loulou_yurika（ねこのゆりか）。3D 文件由作者分发。[模型和使用条款](https://booth.pm/ja/items/4613310)
