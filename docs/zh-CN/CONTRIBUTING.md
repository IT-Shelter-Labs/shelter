# 为 Shelter 贡献代码

[English](../../CONTRIBUTING.md) · [Русский](../ru/CONTRIBUTING.md) · [日本語](../ja/CONTRIBUTING.md) · **简体中文**

请在独立分支上开发，说明问题、改动内容和验证步骤。报告故障时，请提供操作系统、语音模式、模型、复现步骤及已去除个人信息和凭据的日志片段。[构建与测试命令](GUIDE.md)

修改音频处理时，请保持采样率、PCM 格式、中止行为和首段音频延迟，并检查原生实现与回退实现。界面改动应在浏览器开发环境和原生应用中分别验证。请勿提交模型权重、凭据、个人记忆或语音样本。
