# 报告安全问题

[English](../../SECURITY.md) · [Русский](../ru/SECURITY.md) · [日本語](../ja/SECURITY.md) · **简体中文**

如果仓库提供私密漏洞报告渠道，请通过该渠道提交。请勿在公开 Issue 中上传访问令牌、API 密钥、语音样本、个人记忆或完整日志。

Shelter 以桌面用户权限执行操作。请使用可信来源提供的 MCP 服务器、扩展和 Shell 工作流。本地 API 需要令牌，手机需要配对。请将桌面控制 API 保留在本机，通过受支持的手机连接方式访问电脑。[连接设置](GUIDE.md)
