# Возможности по платформам

Состояние на 17.11.2026. «Код есть» не означает проверку на настоящем рабочем столе. Linux-адаптеры проверены модульными тестами в Ubuntu WSL; графический сеанс и реальное звуковое устройство пока не проверены.

| Возможность | Windows 10/11 | Linux X11 | Linux Wayland |

| Микрофон, распознавание (vosk/GigaAM) | проверено | код есть (sounddevice + PortAudio) | как X11 |
| Озвучка Piper/Silero | проверено | код есть | как X11 |

| Громкость | проверено (pycaw) | код есть (`pactl`) | как X11 |

## Проверено на Linux

В WSL Ubuntu 24.04 / Python 3.12 с отдельно загруженными официальными колёсами NumPy, psutil, PyYAML, Pillow и ruamel.yaml:

- импортируются `scenarios`, `packs`, `triggers`, `companion_devices`, `plugins_manager`, `persona_package`, `textops` и `demo_recorder`;
- возможности зависят от графического сеанса и установленных инструментов; XWayland не выдаётся за полную поддержку Wayland;
- проверены отрицательные координаты мониторов, ввод Unicode без shell, отказ вставки при потере исходного окна/фокуса, восстановление буфера;
- `tests.test_desktop_linux`, `tests.test_plugins`, `tests.test_plugin_catalog`: **25 тестов прошли**;
- запись демонстрации по-прежнему Windows-only и сообщает об ограничении.

## Не проверено на Linux

Полный запуск с микрофоном, распознаванием и голосом, окно Tauri, трей, установщик и глобальные клавиши в настоящем сеансе. Локальную сборку Tauri не удалось выполнить: APT в доступной Ubuntu не обновляет индекс из-за DNS и получает 404 на старые версии пакетов. Это ограничение проверки, а не успешная Linux-сборка. CI дополнен отдельной сборкой на Ubuntu 24.04, но её удалённый запуск здесь не выполнялся.

Windows-зависимости (`pycaw`, `ctypes.windll`) импортируются только после проверки `os.name == "nt"`.

## Подготовка Ubuntu 24.04

`bash tools/setup_linux.sh` устанавливает официальные системные зависимости и создаёт отдельную `.venv-linux`, не затрагивая Windows `.venv`. Затем `.venv-linux/bin/python main.py`. Скрипт использует sudo только для пакетного менеджера; Python запускается от обычного пользователя.

Для окна нужны Node 22.12+ и актуальный Rust stable: из `app` выполните `npm ci`, `npm run check`, `npm run desktop:build`. Tauri автоматически берёт `tauri.linux.conf.json`; Windows HUD не включается в Linux-ресурсы. Для установщиков: `npm run desktop:bundle`. Перед публичным выпуском необходима живая проверка на Linux со звуком.

Встроенный персонаж использует WebKitGTK и VRM; ограничения прозрачности/кликов/always-on-top зависят от композитора. Портал Screenshot требует `python3-gi` у системного `/usr/bin/python3` (не установки GI в venv).
