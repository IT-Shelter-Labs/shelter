## Установка и первый запуск

**Windows.** Скачайте x64-установщик со страницы [выпусков GitHub](https://github.com/IT-Shelter-Labs/shelter/releases). Запустите его, выберите папку и установите голосовые компоненты через мастер. Проверьте микрофон перед включением голосового вызова. Для разового запроса нажмите **«Говорить»**. Кнопка **«Стоп»** прерывает прослушивание, озвучку или действие. При первом запуске имя вызова — `Пиппа`. Если персонаж уже выбран, приложение использует сохранённое имя.

**Linux.** Архив x86_64 собран для Ubuntu 24.04. Установите системные пакеты, затем откройте терминал в папке распакованного архива.

```bash
sudo apt install python3 python3-venv libportaudio2 libgtk-3-0t64 libwebkit2gtk-4.1-0 libayatana-appindicator3-1 librsvg2-2
python3 tools/install_linux.py --light-recognition
"${XDG_DATA_HOME:-$HOME/.local/share}/Shelter/shelter"
```

Ключ `--light-recognition` устанавливает Vosk без GigaAM. Чтобы выбрать другую новую папку установки, укажите `--directory`. В архив входят графическое приложение и нативная аудиобиблиотека. Громкость управляется через `pactl`, плееры через `playerctl`. В Wayland поддержка окон, сочетаний клавиш и захвата выделения зависит от композитора. Можно начать с кнопки **«Говорить»** или текстового ввода. Сборка и запуск проверены в Ubuntu через WSL. Проверки звука на физическом устройстве и в разных графических окружениях ещё впереди.

## Голос, персонажи и сценарии

- В **«Настройки → Голос и слух»** выбираются микрофон, распознавание и озвучка. GigaAM и Vosk на ПК распознают русскую речь. Язык интерфейса не меняет язык распознавания. Здесь также можно выбрать установленное совместимое речевое дополнение.
- В разделе **«Персонаж»** выберите пресет или отредактируйте копию. Чтобы подключить исходный облик Пиппы, откройте **«Страница 3D-модели»**, скачайте у автора `08_Pippa.zip` и распакуйте архив. Откройте редактирование Пиппы, на вкладке **«Облик»** выберите `.vrm`, сохраните копию и активируйте её. Облик Мандзю входит в комплект. Модель Юки скачивается при выборе. [Модель Пиппы и условия автора](https://booth.pm/ja/items/4613310) · [Авторы и лицензии](THIRD_PARTY.md)
- Поддерживаются гуманоидные VRM 0.x/1.0 со встроенными текстурами и движения VRMA. Импортируйте их из раздела **«Персонаж»** и укажите автора. Параметры окна зависят от платформы. Персонажа можно оставить на экране постоянно или показывать только во время разговора. [Подробности об обликах и анимации](../AVATARS.md)
- В **«Команды → Новый сценарий»** добавьте шаги, условия и триггеры. Проверьте сценарий перед запуском по расписанию. Триггеры включают кнопку, голос, время и события. Разовая голосовая цепочка может объединять до шести поддерживаемых шагов. Например, `Открой калькулятор, поставь громкость на тридцать, потом напомни через три минуты выпить воды`. Успешную цепочку можно сохранить с карточки задачи. При остановке уже выполненные шаги остаются в силе. [Подробности о сценариях](../SCENARIOS.md)

## Модели и дополнения

1. В **«Настройки → Модели и разум»** добавьте локальное или облачное подключение. Укажите адрес, ID модели и ключ, если провайдер его требует. Здесь же отдельно назначьте модели для общения, сложных задач и материалов, зрения. Для зрения нужна модель с поддержкой изображений. Ей передаются вопрос и запрошенный снимок. В Alibaba Model Studio адрес и ключ должны относиться к одному региону и рабочей области. OpenAI-совместимый путь — `/compatible-mode/v1`.
2. В **«Настройки → Голос и слух»** для облачной озвучки выберите подключение, API, ID модели и ID голоса, затем проверьте воспроизведение. OpenAI-совместимое API использует `/audio/speech` с ответом WAV. Alibaba Qwen Audio использует свой API. При сбое используется установленный локальный голос.
3. В **«Создание изображений»** выберите подключение с поддержкой `/images/generations` и PNG в поле `b64_json`. Готовые изображения сохраняются в `data/generated`. Запросы к облаку выполняются по условиям и тарифам провайдера.
4. В **«Подключения»** настраиваются телефон, умный дом, OBS, Telegram и MCP. **«Дополнения»** принимает пакеты `.jarvis-plugin.zip`. Перед включением проверьте разрешения. Дополнение запускается в отдельном процессе с доступом текущего пользователя, поэтому устанавливайте пакеты из доверенных источников. Поддерживаются действия, речь, события, виджеты и реакции персонажей. [Облачные модели](../CLOUD_MODELS.md) · [Формат дополнений](../PLUGINS.md)

## Android

**Shelter** работает на Android 8+. **Shelter Local** требует Android 12+ и добавляет чат с моделью на устройстве. Варианты можно установить рядом.

- **Облако.** Выберите провайдера или OpenAI-совместимый API, укажите ключ и ID модели. Системный голос выбирается в **«Голос и микрофон»**. Запросы идут провайдеру, история хранится на телефоне.
- **Мой компьютер.** На ПК откройте **«Подключения → Телефон»**, включите доступ в домашней сети и запишите адрес, обычно порт `8765`. Введите адрес в телефоне и выполните сопряжение по коду из приложения на ПК. Для домашнего HTTP отдельно разрешите LAN. Из внешней сети нужен HTTPS с действительным сертификатом. Когда включена озвучка ПК, телефон воспроизводит его голос, а **«Стоп»** прерывает задачу на компьютере. Доступ можно отозвать на ПК.
- **На устройстве.** В Shelter Local откройте **«Настройки → На устройстве»** и скачайте Qwen3 0.6B (около 347 МБ). Приложение проверяет архитектуру, память, свободное место и файл. Загрузку можно отменить. Есть ручной импорт совместимого `.litertlm`. Предлагаемая модель рассчитана на короткие запросы.
- **Фоновый микрофон.** Скачайте пакет русского Vosk в **«Голос и микрофон»**, включите прослушивание в открытом приложении и выдайте запрошенные разрешения. Скажите `Слушай, помощник`, дождитесь сигнала и произнесите запрос. Остановить прослушивание можно из приложения или постоянного уведомления. Сеанс длится до 30 минут. После перезагрузки его нужно включить заново. Загрузка моделей и управление фоновым режимом проверены в эмуляторе. Расход батареи и работа с микрофоном на физическом телефоне ещё не проверены. [Подробности для Android](../ANDROID_CLIENT.md)

## Разработка, тесты и выпуск

Команды Windows приведены в [README](README.md). На Ubuntu 24.04 выполните `bash tools/setup_linux.sh` из корня проекта, чтобы установить зависимости и создать `.venv-linux`. Для графической сборки нужны Node.js 22.12+, Rust и пакеты разработки GTK/WebKitGTK. С окружением Python в `PATH` выполните `npm --prefix app ci` и `npm --prefix app run desktop:build`.

Проверки запускаются из корня репозитория в окружении Python проекта.

```sh
python tools/build_native.py
python -X utf8 -m unittest discover -s tests
npm --prefix app run check
npm --prefix app run test:avatar
npm --prefix app run test:navigation
npm --prefix app run test:i18n
npm --prefix app run build
cargo test --locked --manifest-path app/src-tauri/Cargo.toml --lib
```

Для Android потребуются JDK 21, SDK Platform 35 и Build Tools 36.0.0. Выполните в `android/` на Windows.

```powershell
.\gradlew.bat --no-daemon :app:assembleCompanionDebug :app:assembleLocalDebug :app:testCompanionDebugUnitTest :app:testLocalDebugUnitTest
```

На Linux используйте `./gradlew` с теми же аргументами. Команда `python tools/export_public.py release/github-source` создаёт новый снимок с переводами, без личных данных и рабочей истории Git. Собирайте из него пакеты релиза и сверяйте контрольные суммы перед публикацией. [Подготовка выпуска](../PUBLIC_RELEASE.md) · [Вклад в разработку](CONTRIBUTING.md)

## Данные, безопасность и лицензии

В публичные issues не добавляйте токены, образцы голосов, личную память и полные журналы. Сообщайте об уязвимостях через закрытый канал репозитория, если он доступен. Локальный API требует токен, а телефон — сопряжение. Для доступа с телефона используйте штатное подключение.

Код Shelter распространяется по [лицензии MIT](../../LICENSE). Для моделей, портретов, VRM и зависимостей действуют отдельные условия. Авторы и исходные лицензии приведены в [уведомлениях](THIRD_PARTY.md).
