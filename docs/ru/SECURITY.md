# Сообщения об уязвимостях

[English](../../SECURITY.md) · **Русский** · [日本語](../ja/SECURITY.md) · [简体中文](../zh-CN/SECURITY.md)

Если в репозитории доступен закрытый канал для сообщений об уязвимостях, воспользуйтесь им. В публичные issues не добавляйте токены, API-ключи, образцы голосов, личную память и полные журналы.

Shelter выполняет действия с правами текущего пользователя компьютера. Подключайте MCP-серверы, дополнения и сценарии с командами оболочки из доверенных источников. Локальный API требует токен, а телефон — сопряжение. Оставляйте API управления на компьютере и используйте штатное подключение телефона. [Настройка подключения](GUIDE.md)
