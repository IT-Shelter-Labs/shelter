# Подготовка релиза Shelter

В старой истории Git уже встречаются записи голоса, отчёты и личный config.yaml.
`.gitignore` не убирает ранее отслеживаемые файлы и старые коммиты.
Не публикуйте существующую историю целиком.

Создайте НОВУЮ папку исходников:

```powershell
python tools/export_public.py release/github-source
```

Копируются исходники, тесты, lock-файлы, CI, выбранная документация,
снимки интерфейса, лицензии, иконки и анимации с атрибуцией. Вместо личного config.yaml используется
config.public.yaml. Исключены Git-история, data, модели, голоса, датасеты,
загрузки персонажей, окружения, сборки, отчёты и локальные настройки Android.
Личный проект остаётся на месте. Экспорт включает публичные пресеты,
разрешённые портреты и 3D-облик Мандзю. Образцы голоса и VRM из пользовательского
каталога не копируются. Список материалов и условия описаны в [THIRD_PARTY.md](../THIRD_PARTY.md).

Перед первым публичным выпуском:

- Для собственного кода выбрана [лицензия MIT](../LICENSE). Сторонние лицензии указаны в [THIRD_PARTY.md](../THIRD_PARTY.md).
- Соберите снимок по README. Создавайте новый репозиторий из этой папки,
  без переноса `.git` рабочего проекта.
- Проверьте права на добавленные сторонние материалы; сохраните NOTICE.
- Проверьте установку на чистом Windows-профиле, реальном Linux и Android.
- Если действующие ключи раньше публиковались, замените их у сервисов:
  исключение файла из нового снимка не отзывает ключи.
- На странице репозитория укажите, какие платформы проверены, и добавьте
  скриншоты чистого профиля. Установщик и APK приложите к релизу вместе с
  SHA-256. Пробные APK подписаны отладочным ключом, для релиза нужен свой ключ.

Скрипт ничего не отправляет на GitHub и не изменяет старую историю.

## Собрать папку выпуска

Подготовьте NSIS-установщик из чистого снимка. Соберите Linux x86_64 в
Ubuntu 24.04 и положите исполняемый файл Tauri в папку сборки под именем
`shelter-desktop`, библиотеку из `bin/libjarvis_native.so` — рядом с ним.
Для Android соберите единый APK в режимах Debug и Release.
Не передавайте ключ подписи вместе с комплектом.

```powershell
python tools/package_release.py release/Shelter-0.1.0-alpha.3 --windows <installer.exe> --linux <linux-build-dir>
```

В папке выпуска будут чистый репозиторий, архив исходников, установщик
Windows, архив Linux, тестовые и неподписанные APK и контрольные суммы.
Для публикации Android выберите постоянный ключ издателя. Тестовые APK
используют отладочную подпись. [Подпись Android](https://developer.android.com/studio/publish/app-signing).
