# Нативная часть и расход памяти

`native/` собирается как `jarvis_native.dll` / `libjarvis_native.so`. Версия C ABI
проверяется при загрузке. Python передаёт NumPy-буферы через ctypes;
дополнительного процесса и копии нейросетевых весов нет.

Перенесены: полифазный FIR-ресемплер Kaiser(beta=5), кольцевой буфер захвата,
чтение и адресное управление медиасессиями Windows. Фильтр сохраняет длину,
фазу, частоты среза и обработку краёв прежнего `scipy.signal.resample_poly`.
Тесты сравнивают короткие фрагменты, случайные сигналы, 32/44.1/48 кГц,
изменение высоты, подавление частот выше нового предела Найквиста.

SciPy загружается только для резервного ресемплера и необязательного
старого детектора звуков. WAV читает libsndfile, без scipy.signal.
Когда детектор выключен, микрофон не наполняет его вторую очередь.

Замер 17.11.2026: медиана трёх отдельных процессов на машине разработки,
100 пересчётов по 8192 float32-отсчёта, 32 → 16 кГц:

| Метрика | прежний импорт SciPy | Rust |
|---|---:|---:|
| RSS Python после импорта ядра и пересчёта | 107.5 МиБ | 44.8 МиБ |
| запуск диагностического процесса | 1.69 с | 0.64 с |
| один пересчёт, медиана | 181.5 мкс | 89.6 мкс |

Это **не общий расход работающего ассистента**: не включены веса ASR, Ollama,
сервера голоса и WebView. Повторить: `python tools/benchmark_runtime.py`.
Результат зависит от машины и файлового кэша.

Python сохраняет интеграцию с sherpa-onnx/vosk, голосовыми моделями, словарями
русского языка и расширениями. Перенос управляющих модулей сам по себе
не уменьшит вес ONNX/GPU-моделей. Полная замена управляющего ядра на Rust
в этой версии не выполнялась; требуется отдельная миграция API и тестов.

Отключить Rust для диагностики: `JARVIS_NATIVE=0` в окружении до запуска.
На Linux медиасессии обслуживает playerctl, Rust используется для аудио.
