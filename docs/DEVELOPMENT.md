# Разработка окна

## Нативный runtime и публичные исходники

`python tools/build_native.py` собирает `native/` и, на Windows, HUD; публикует
библиотеку в `bin/`. `npm run desktop:build` и `desktop:bundle` вызывают этот
шаг автоматически. Уже совпадающий по SHA-256 файл повторно не копируется.
Изменённая DLL требует закрытия приложения через меню трея.

`native_runtime.py` проверяет ABI, связывает NumPy-буферы и сохраняет резервный
путь. Проверки аудио: `tests/test_native_runtime.py`. В публичном CI библиотека
собирается до Python-тестов. Замеры и границы переноса: [RUNTIME.md](RUNTIME.md).

Для публикации используйте `tools/export_public.py` и новую историю Git —
см. [PUBLIC_RELEASE.md](PUBLIC_RELEASE.md). Снимок не включает личные модели,
голоса и config.yaml. При его отсутствии приложение читает config.public.yaml.

## Обновление Windows-версии в папке проекта

Пользователь запускает `bin/jarvis.exe`. После `npm --prefix app run desktop:build`
новый файл появляется в `app/src-tauri/target/release/Jarvis.exe`; это ещё не
обновление `bin/jarvis.exe`. Закройте приложение через «Выход» в трее, сохраните
резервную копию старого EXE и скопируйте новый в `bin/jarvis.exe`.

Обе точки запуска внутри репозитория используют корень проекта: существующие
`data/settings.json`, память, персонажей, `.venv` и модели. Соседняя с release-сборкой
папка `core/` — подготовленные ресурсы публичного установщика; она не должна
перехватывать данные проекта. В настоящей установленной версии вне репозитория
используется её собственная `core/`. Явное `JARVIS_CORE` имеет приоритет.

Обновление EXE не требует повторной установки Python, моделей или голосов.
Перед передачей пользователю проверьте именно `bin/jarvis.exe`: вход сразу на
главный экран и карточку Джарвиса с реактором. Браузерный мост ниже не проверяет
разрешённые адреса нативного IPC и поиск папки проекта.

## Окно в обычном браузере на тестовом ядре

```bash
.venv/Scripts/python tools/dev_core.py logs/dev-core 8771
```

```bash
npm --prefix app run dev:bridge
```

Затем откройте http://localhost:1430.

Тестовое ядро (`tools/dev_core.py`) — это настоящий ControlServer со сценариями, проверкой фраз, наборами, дополнениями и подключениями. В нём нет:

- микрофона, распознавания и синтеза речи;
- исполнения шагов: громкость, клавиши, окна, программы и медиа только печатаются, компьютер не трогается.

Сценарии, резервные копии, дополнения, устройства телефона, свои персонажи,
выбор персонажа, база разговоров и копия настроек хранятся в папке тестового
ядра, а не в `data/`. Встроенные персонажи читаются из проекта; выбор на стенде
не запускает озвучку или отдельное окно персонажа.

Для отдельного ключа стенда задайте в терминале Vite переменную
`JARVIS_BRIDGE_TOKEN_FILE` с абсолютным путём к `<папка-стенда>/control.token`.
Без переменной мост использует прежний `data/control.token`.

Vite в режиме `bridge` подменяет `@tauri-apps/*` заглушками из `app/src/dev/` и проксирует вызовы в тестовое ядро (порты 8771 и 8772). В сборку приложения мост не попадает.

## Язык интерфейса

Переключатель: «Настройки → Оформление → Язык интерфейса». `ui.language` принимает
`ru` или `en`, сохраняется как обычная настройка и применяется сразу, включая
меню трея и окно персонажа. Язык распознавания и озвучки не меняется.

Подписи переводит `app/src/lib/i18n.svelte.ts`; чистое ядро перевода и формы
числа находятся в `i18n.ts`, английский словарь — в `locales/en.json`. Переводите
подписи и системные сообщения при показе. Не переводите сообщения пользователя,
реплики модели, содержимое памяти, имена, пути и исполняемые голосовые фразы.
Данные выводятся обычными текстовыми узлами, без HTML из ответов модели.

`node app/tools/localize-ui.mjs` собирает инвентарь в `reports/ui-i18n-source.json`
(из корня проекта, с установленными зависимостями `app`). Затем
`python tools/extract_ui_messages.py` добавляет метаданные и ошибки ядра и
оставляет только отсутствующие в английском словаре строки. `--apply` у первой
утилиты — отдельная миграция представления; для обычной проверки он не нужен.
`npm --prefix app run test:i18n` проверяет переводы, данные, формы числа и язык.
