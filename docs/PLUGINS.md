# Дополнения (плагины)

Дополнение — пакет `*.jarvis-plugin.zip`: действия, речевые движки, события, виджеты и реакции персонажа.

## Расширения кроме действий

`kinds` может содержать `tts`, `stt`, `trigger`, `widget`, `reaction`. В `main.py` нужна одноимённая функция `(params, context)`; случайный `run` вместо неё не вызывается.

- `tts`: получает `text` и `language`; возвращает `{encoding: "pcm_s16le", sample_rate: 24000, audio: "base64..."}`. Моно, 8–48 кГц, до 60 секунд. Выбор: «Слух и голос → Речевые дополнения»; настройки — `tts.plugin.settings`.
- `stt`: получает `audio` (base64 PCM16), `sample_rate: 16000`, `language`; возвращает `{text: "..."}`. Настройки — `asr.plugin.settings`.
- `widget`: возвращает `{title, text, rows: [{label, value}]}`. Строки выводятся как текст, HTML/JavaScript не исполняются. На главной включить карточку «Виджеты дополнений»; скрытая карточка не опрашивается.
- `trigger`: получает `event`, возвращает `{active: true/false, key: "идентификатор события"}`. В сценарии выбрать «Событие дополнения», его ID и имя события. Первый опрос создаёт базовое состояние; затем срабатывает переход false→true или смена key при active=true. Применяются обычные условия и cooldown сценария.
- `reaction`: получает только `state`, возвращает короткое движение `{animation: "nod"}` (`wave`, `nod`, `bow`). Работает вне голосового потока, пропускает устаревшие ответы и ограничивает частоту. Отключение реакций персонажа отключает этот путь.

Глобальное разрешение дополнений и выключатель конкретного пакета действуют для всех типов. Речь/ASR используют общую отмену задачи; виджеты и события ограничены таймаутом. Пример `plugins/catalog-src/desk-clock` показывает виджет и событие без внешних зависимостей.

## Где работает и чего не обещает

- Каждый вызов идёт в **отдельном процессе** (`plugin_host.py`) с ограничением времени (30 с) и памяти (512 МБ).
- Зависшее или упавшее дополнение получает понятную ошибку, а голосовой цикл продолжает работать.
- Это **не защищённая песочница**: у дополнения те же права, что у пользователя Windows. Ставьте только то, чему доверяете.
- Дополнению передаются только его параметры и его настройки (`plugins.<id>` в настройках), а не весь конфиг с ключами.

## Манифест `plugin.json`

```json
{
  "format": "jarvis.plugin", "format_version": 1,
  "id": "quick-notes", "name": "Быстрые заметки", "version": "1.0.0",
  "author": "Джарвис", "description": "…", "license": "MIT", "source": "…",
  "core": ">=2.0", "platforms": ["windows", "linux"],
  "kinds": ["action"],
  "permissions": ["files"],
  "entry": "main.py",
  "changes": "Что нового в версии",
  "actions": [
    {"id": "append", "label": "Записать заметку",
     "fields": [{"key": "text", "label": "Текст заметки", "kind": "textarea", "required": true}]}
  ]
}
```

- **Права:** `network`, `files`, `keyboard`, `clipboard`, `processes`, `microphone`, `screen`. Их показывают человеку перед установкой.
- **Типы:** `action`, `tts`, `stt`, `widget`, `trigger`, `reaction`. Пакет объявляет один или несколько типов в `kinds`.
- **Код:** функция с именем действия (или `run`) принимает `(params, context)` и возвращает JSON-совместимое значение.
- **Ответ голосом:** если вернуть `{"say": "…"}`, Джарвис это произнесёт.

## Установка и обновления

- Установленные дополнения лежат в `data/plugins/<id>/<версия>/`, активная версия записана в `data/plugins/state.json`.
- **Обновление** ставится рядом с текущей версией. Прежняя версия остаётся, её можно вернуть: «Подключения» → «Дополнения» → кнопка с номером версии.
- **Оборванная установка** (битый архив, ошибка распаковки) не трогает рабочую версию.
- **Встроенный каталог** лежит в `plugins/catalog/`, собирается из `plugins/catalog-src/` командой `python tools/build_plugin_catalog.py`.
- **Старые одиночные `plugins/*.py`** продолжают работать, теперь тоже в отдельном процессе.

Платёжная система и подписи издателей не добавлены. Найденный в интернете MCP-сервер не считается доверенным автоматически.

## Дополнительные типы

У каждого типа своя функция `(params, context)`: `tts`, `stt`, `widget`, `trigger`, `reaction`. Если функция отсутствует, вызов сообщает об ошибке; `run` её не подменяет.

| Тип | Вход | Результат |
|---|---|---|
| `tts` | `text`, `language: ru` | `encoding: pcm_s16le`, `sample_rate: 8000..48000`, `audio`: base64 моно PCM16, максимум 60 с |
| `stt` | `audio`: base64 PCM16 mono 16000 Hz, `language: ru` | `text`, до 16000 знаков; фраза до 90 с |
| `widget` | `{}` | `title`, `text`, `rows: [{label,value}]`; только текст, без HTML/JS |
| `trigger` | `event`: имя события | `active: bool`, `key`: идентификатор события; запуск при новом ключе/переходе false→true |
| `reaction` | `state`: listening/thinking/speaking/confirm/error | `animation`: wave/nod/bow; короткие реакции, с ограничением частоты |

Речевые движки выбираются в «Настройки → Голос и слух». Виджеты включаются в раскладке главной; по умолчанию скрыты. Событие дополнения доступно в конструкторе сценариев. Пример `desk-clock` содержит часы и событие смены минуты. Изменение голоса требует применения движка; параметры обычных дополнений применяются без перезапуска.

`context.settings` содержит только параметры этого дополнения. В манифесте можно объявить `settings_schema` (JSON Schema: `properties`, `required`, `type`, `default`, `enum`, `minimum`, `maximum`, `maxLength`). Формы поддерживают строки, числа, целые и переключатели. Например:

```json
"settings_schema": {
  "type": "object",
  "properties": {
    "api_key": {"type":"string", "format":"password", "title":"Ключ сервиса"},
    "speed": {"type":"number", "minimum":0.5, "maximum":2, "default":1, "title":"Скорость"}
  }
}
```

Секретные параметры называйте `api_key`, `token`, `password`, `secret` или именем с таким суффиксом через `_`: Windows защищает их DPAPI; Linux сохраняет настройки с правами 0600. Права манифеста описательные: процесс дополнения имеет права пользователя. Не включайте чужой код без доверия к автору.

## Подключаемый источник

«Подключения → Дополнения → Другой источник» принимает HTTPS-адрес `index.json`. Загрузка списка ничего не устанавливает. Перед установкой скачивается архив, проверяются SHA256 и манифест, затем показываются автор, лицензия и права. Устанавливаются ровно просмотренные байты; изменение архива/каталога отменяет установку. SHA256 не является подписью автора.

Формат: `{"format":"jarvis.catalog","version":1,"name":"…","packages":[{"id":"…","name":"…","version":"1.0.0","file":"package.zip","sha256":"64 hex"}]}`. Архивы находятся на том же источнике. Встроенный пример `plugins/catalog/index.json` генерируется `tools/build_plugin_catalog.py`.

Для локальной демонстрации запустите `python -m http.server 8790 --bind 127.0.0.1 --directory plugins/catalog`, укажите `http://127.0.0.1:8790/index.json` и включите «Локальная демонстрация». Внешний HTTP не допускается. Сервер нигде не публиковался.
