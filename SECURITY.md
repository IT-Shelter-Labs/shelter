# Сообщения об уязвимостях

Не публикуйте токены, API-ключи, образцы голосов, личную память и полные журналы
в публичных issues. До публичного релиза настройте GitHub Private Vulnerability
Reporting. Пока закрытый канал не настроен, секретные данные публично не отправляйте.

Приложение действует на компьютере от имени пользователя. MCP, плагины и
shell-сценарии подключайте из доверенных источников. Локальный API требует токен;
телефон требует сопряжения. Не открывайте локальный порт в интернет без защиты.
