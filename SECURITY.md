# Reporting security issues

**English** · [Русский](docs/ru/SECURITY.md) · [日本語](docs/ja/SECURITY.md) · [简体中文](docs/zh-CN/SECURITY.md)

Use the repository’s private vulnerability reporting channel when available. Keep tokens, API keys, voice samples, personal memory, and full logs out of public issues.

Shelter performs actions with your desktop user’s permissions. Connect MCP servers, extensions, and shell workflows from sources you trust. The local API requires a token, and the phone connection requires pairing. Keep the desktop control API on the local machine. Use the supported companion connection to reach your PC from a phone. [Connection setup](docs/GUIDE.md)
