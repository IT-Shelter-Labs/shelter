# Плагины действий

Каждый плагин — один Python-файл с функцией `run(params, context)`. В цепочке
он вызывается так:

```yaml
- type: plugin
  name: example
  params:
    message: "Моя функция запущена"
```

Имя может содержать только латинские буквы, цифры и `_`; импортировать модуль
из другой папки нельзя. Плагин является исполняемым кодом: включайте
`security.allow_plugins` только для файлов, которым доверяете.
